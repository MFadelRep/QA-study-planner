# QA Study Planner — Senior QA Automation + MLOps

This repository is the authoritative study-control system for the Senior QA Automation + MLOps curriculum. It stores study state, study rules, curriculum scope, derived handovers, reusable evidence-backed technical lessons, and validation—not the AI QA Platform application itself.

## Start a new study chat
Type `STUDY`. The assistant must read the GitHub Study Control Center before resuming, use the current state as the live checkpoint, and continue from its exact next action.

## Study commitment
The 45-hour curriculum is the capability catalogue. The accelerated seven-day plan targets about six focused hours per day by combining overlapping capabilities into integrated project batches. Breadth and working evidence come first; deep explanations are provided on demand or when a concept blocks progress. This is an accelerated preparation plan, not a guarantee of complete mastery in 42 clock hours.

The authoritative batch-first workflow and all execution rules live in `study-control-center/04_CONTINUITY_RULES.md`. Read that file rather than relying on a summary in this README. Use `study-control-center/09_LESSONS_LEARNED.md` for relevant reusable lessons; it never replaces the live checkpoint or curriculum.

## Project separation
The local **AI QA Platform** lives in a separate project repository. Do not connect it as this repository's remote or store application code here. This repository manages study progress only.
